# 设计参考（来自 GitHub 调研，只借思路，未复制任何代码）

- 数据模型三表：sessions（日期、场馆、类型、评分、笔记）；climbs（难度 V/YDS/法式、尝试次数、结果 Flash/Send/Attempt/Project）；training（动作、组数、次数、重量或时长）。
- 统计：难度趋势、完攀率、每周训练量。
- UI：首页大数字（本周次数、本周最高完攀、累计次数）；底部 3 Tab：记录 / 统计 / 我的；难度用宫格或分段控件，点击区大，岩馆里单手能记完。
- 视觉：系统字体（SF / PingFang SC），字重对比大，大号数字 tabular-nums；大量留白，卡片少阴影，细分割线；图表细线、浅色坐标轴；浅色为主 + 类 iOS Health 深色模式；只用一个点缀色；不用 emoji。
- 后续：指力板计时、日历与训练计划、云同步与微信登录。
